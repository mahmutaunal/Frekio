# Branding

## Final working brand: Frekio

Why the earlier working name was changed:
- “Ahenk” is already used by a Turkish radio station (“Radyo Ahenk”), creating avoidable confusion for a radio aggregator.
- Frekio is short, ASCII-only, easier to distinguish in store search, and evokes “frequency” without being tied to one language.
- The package/application ID is `com.alpwarestudio.frekio`.

This is a product-name availability screen, not legal trademark clearance. Run a formal trademark check before commercial launch if the brand becomes valuable.

## Visual direction

- Calm, low-distraction media player.
- One strong symbol: broadcast waves/frequency pulse.
- Rounded geometric icon suitable for Android adaptive icon and iOS squircle mask.
- No tiny text or literal “FM” badge.
- Material 3 on Android, native typography/spacing expectations on iOS, with shared product identity.
