# Changelog

## Unreleased

- Restored a zero-warning, fully compiling Flutter codebase and expanded tests.
- Added native CarPlay Favorites/Recent browsing with cold-start engine support.
- Added Android and iOS 17+ interactive playback widgets.
- Added Android Auto voice search, last-station restoration and improved media metadata.
- Introduced a cross-platform Liquid Glass-inspired design system with ambient
  depth, floating playback/navigation controls and non-blurred content surfaces.
- Rebuilt discovery, search, favorites, settings and now-playing experiences for
  phone, tablet, light/dark mode, reduced motion and high-contrast preferences.
- Rebuilt Settings around the AlpWare Studio identity with website, support,
  privacy and open-source license destinations.
- Redesigned Android and iOS widgets as event-driven artwork media cards with
  adaptive system corners and native playback intents.
- Expanded system media controls with previous/next station navigation, richer
  live metadata, branded color and platform-owned MediaStyle/Now Playing UI.
- Migrated iOS plugins to Swift Package Manager and removed debug release signing.
