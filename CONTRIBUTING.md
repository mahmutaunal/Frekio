# Contributing

1. Use the current stable Flutter channel.
2. Keep dependencies minimal and avoid paid/closed runtime services unless discussed first.
3. Run `dart format .`, `flutter analyze`, and `flutter test`.
4. Do not hardcode a station catalogue into source.
5. Do not add analytics, advertising, tracking, account systems or broad device permissions by default.
6. Preserve Turkish and English UI coverage for user-facing strings.
7. New background tasks must include a battery-impact justification.
